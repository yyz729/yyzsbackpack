### 简介
**Yyz’s Backpack** 是一款轻量、便捷的背包模组，旨在不破坏原版UI风格的前提下，为玩家提供更高效的物品管理体验。背包可直接在各类界面（如工作台、箱子、熔炉等）中打开，并支持与合成、整理、快速移动等操作。

## ✨ 特色
- **随处访问**：背包界面会直接显示在多种容器界面上，无需切换即可拿取或放入物品。
- **合成辅助**：支持直接使用背包内的物品进行合成，兼容配方书与 JEI，并支持一键快速填充。
- **染色系统**：背包可像皮革装备一样任意染色，个性化你的背包外观。
- **背包模型**：装备背包后显示 3D 模型，可通过配置文件隐藏。
- **一键整理**：内置物品整理功能，点击按钮或按下自定义按键（默认未绑定）即可整理，支持多种排序方式（按创造模式物品栏、名称、数量、ID等），可通过对整理按钮滚动切换。
- **快速移动**：Shift + 右键将物品存入背包，Shift +左键正常移动物品，也可使用按钮批量快速移动，支持移动相符物品或移动全部物品。
- **快速切换**：点击背包上方的标签页可快速切换背包，标签页会显示背包名字和外观；也可以按热键（默认 `B`）打开当前鼠标选中的背包。
- **自动收纳**：当物品栏已满时，新获得的物品会自动进入背包。
- **负重系统**：当同时携带多个背包（默认3）或更多时，获得负重效果，降低移动速度和跳跃高度

## 📦 安装与使用

1. 安装对应 Minecraft 版本的 **Fabric** 或 **Forge** 或 **NeoForge**模组加载器。
2. 下载模组 `.jar` 文件，放入游戏目录下的 `mods` 文件夹中。
3. 进入游戏，将背包放在物品栏内任意位置，若安装了对应模组也可以放在饰品栏。
4. 通过标签页或快捷键选择要使用的背包

#### ❌不兼容
- **所有库存整理类模组**（如 Inventory Tweaks、Mouse Tweaks 等）：
    - 表现：只能整理原物品栏，无法整理背包；或将物品栏和背包混为一体进行整理；无法整理，严重时直接崩溃。
    - 原因：由于本模组的实现方式特殊，无法兼容绝大多数整理类模组，目前未找到通用修复方案。**作为替代，模组内置了完善的整理功能**，足以满足日常需求。

## 🛠 自定义

### 模组配置

**主配置** `/config/yyzsbackpack.json`

| 配置项 | 类型 | 说明 |
|--------|------|------|
| `model` | boolean | 是否显示玩家背上的背包模型 |
| `heavy` | int | 背负多少个背包后获得"负重"效果 |

**按钮位置配置** `/config/yyzsbackpack/control/default.json`

| 配置项 | 类型 | 说明 |
|--------|------|------|
| `controlPoss` | object | 背包整理、快速移动等按钮在各类界面中的坐标 |

**界面偏移配置** `/config/yyzsbackpack/ui/default.json`

| 配置项 | 类型 | 说明 |
|--------|------|------|
| `uiOffsets` | object | 背包界面在各个容器界面中的整体偏移量 |

### 背包自定义（材质包与数据包）
你可以完全重设背包的 GUI 布局、槽位位置及容量，具体可以参考模组文件或Github内的例子。

- **材质包路径**：`assets/yyzsbackpack/backpacks/<文件名>.json`
- **数据包路径**：`data/yyzsbackpack/backpacks/<文件名>.json`

#### 通用属性
| 属性 | 说明 |
|------|------|
| `type` | 背包材料：`iron`、`gold`、`diamond`、`netherite` |
| `segments` | 槽位布局分段列表 |

#### 分段属性
| 属性 | 说明 |
|------|------|
| `startSlot`, `endSlot` | 该分段的槽位索引范围 |
| `order` | `"DEFAULT"`（网格模式，从左到右、从上到下）或 `"CUSTOM"`（自定义每个槽位坐标） |
| `startX`, `startY` | 起始坐标（DEFAULT 模式） |
| `columns`, `rows` | 网格行数、列数（DEFAULT 模式）当槽位数量大于网格数时可滚动显示 |
| `customPositions` | 每个槽位的 `{"x": 数字, "y": 数字}` 数组（CUSTOM 模式）。*注意：CUSTOM 模式下无法使用滚动显示。* |
| `guiTexture` | 自定义 GUI 纹理路径 |
| `backgroundX`, `backgroundY` | 背景相对于原 GUI 左上角的偏移 |
| `maxVisibleTabs` | 同时可见的背包切换标签数量（超出可通过滚轮翻页） |

#### 仅数据包可用的属性
| 属性 | 说明 |
|------|------|
| `size` | 设置背包大小，多人游戏下仅服务端有效 |
| `force_server` | 若为 `true`，服务器强制所有客户端使用此配置（推荐多人游戏时开启） |
